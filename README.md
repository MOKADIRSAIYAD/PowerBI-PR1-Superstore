# Power BI PR1 — Superstore Sales Dashboard

## Project Overview

This project analyzes the Superstore Sales dataset using Microsoft Power BI to create an interactive business intelligence dashboard.

The dashboard provides insights into sales performance, profitability, product categories, regional distribution, and customer purchasing patterns.

The objective is to transform raw sales data into meaningful business insights through data cleaning, data transformation, and interactive visualizations.

## Dataset

- **Name:** Sample Superstore Sales Dataset
- **Source:** Kaggle
- **File Format:** CSV
- **Rows:** Approximately 9,994

## Tools & Technologies

- Microsoft Power BI Desktop
- Power Query Editor
- DAX (Data Analysis Expressions)
- CSV Dataset

## Steps Completed

### 1. Data Connection
- Connected to the Sample Superstore CSV dataset.
- Imported data into Power BI Desktop.

### 2. Data Cleaning & Transformation
- Cleaned and prepared the dataset using Power Query Editor.
- Performed 8+ data transformation operations.
- Checked and corrected data types.
- Prepared columns for analysis.

### 3. KPI Development

Created four KPI cards:

- Total Sales
- Total Profit
- Total Quantity
- Average Discount

### 4. Data Visualization

Created the following visualizations:

- Sales by Category — Bar Chart
- Profit by Region — Bar Chart

### 5. Interactive Filters
- Region Slicer
- Category Slicer

### 6. Report Filtering
- Configured page-level filters.
- Configured visual-level filters.

### 7. Dashboard Formatting
- Applied a custom report theme.
- Improved visual consistency and readability.

### 8. Visual Interactions
- Configured interactions between visuals.
- Tested 3+ visual interaction pairs.

## How to Use

1. Clone or download this repository.
2. Locate the `PR1_Kadir.pbix` file.
3. Open the file using Microsoft Power BI Desktop.
4. Explore the dashboard using the available slicers and filters.
5. Interact with the charts to analyze different business dimensions.
